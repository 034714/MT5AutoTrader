MT5AutoTrader 使用说明
========================

一、快速开始
------------
1. 打开 MT5 终端并登录你要交易的账号（真实下单前还要点亮 MT5 工具栏的"算法交易"按钮）。
2. 双击 start.bat。
3. 浏览器打开 http://127.0.0.1:8900。重复双击不会多开，只会打开已有页面。
4. 停止：双击 stop.bat（会先让交易 Runner 安全退出，再关看板）。

二、训练数据在哪里（Parquet 说明）
----------------------------------
"从 MT5 获取并训练"和"只获取并保存"都会把 K 线保存到数据目录：

    D:\K线数据\

文件名规则是  品种_H1.parquet。注意品种名自带下划线时会出现双下划线，这是正常的：

    ETHUSD_  →  ETHUSD__H1.parquet
    BTCUSD_  →  BTCUSD__H1.parquet
    XAUUSD   →  XAUUSD_H1.parquet

这些文件是训练的"原料"，也可以用于回测。数据目录可以在 trader_config.json 的
kline_cache_dir 里修改。你不需要手工制作或理解 Parquet 文件。

三、续训：接着上次的训练成果继续
--------------------------------
支持的。机制说明：

1. 训练过程中会把"检查点"存到 checkpoints\ 文件夹（ckpt_品种_step_数字.pt）。
2. 只要不勾选"从头训练"，再次训练同一个数据文件时会自动从最新检查点继续，
   并保留历史最优分数作为下限（更差的公式不会覆盖已有策略）。
3. 注意步数规则：训练目标是"总步数"。比如上次跑了 60 步，这次想继续就填
   120 或 9000；如果还填 60，程序会提示"已完成全部步数"而直接跳过。
4. 换新数据续训：先点"只获取并保存"（或直接用"从 MT5 获取并训练"）刷新数据，
   再开始训练即可，新数据会自动生效。
5. 勾选"从头训练"会清除该品种的检查点，从零开始。
6. 训练完成后 Runner 会自动检测策略文件变化并热更新，不用重启
   （如果你运行的还是旧版本 Runner，重启一次即可获得该能力）。
7. 训练周期（M5/M15/M30/H1/H4/D1）在"从 MT5 获取数据"卡片里选，
   不同周期会保存成不同的数据文件，互不覆盖；训练页右侧能看到训练分数曲线。
8. 训练固定使用 CPU：本引擎的公式张量很小，实测 GPU 反而更慢
   （串行调度、host↔device 拷贝占大头），所以软件不再提供显卡加速开关，
   也无需安装任何 GPU 相关的包。

当前提醒：checkpoints\ 文件夹现在是空的——之前那次 BTCUSD_ 60 步试跑没有留下
检查点（步数太少没到保存节点），所以目前没有"上次的成果"可接。想积累训练成果，
用更大的步数（几百步以上）训练即可。

四、目录与文件说明
------------------
主目录只保留你要用的东西；所有代码都在 src\ 里，平时不用碰。

【主目录】
  start.bat                正式启动入口（双击这个）
  stop.bat                 正式停止入口（双击这个）
  说明.txt / README.md     使用说明
  AGENTS.md                给后续 AI 的交接规则（已知的 Windows 坑都记在里面）
  trader_config.json       看板保存的全部配置：dry-run 开关、策略绑定、手数、
                           风控参数（含支撑/阻力优化）、数据目录。删掉会自动重建默认。
  trader_config.example.json  配置模板（开源仓库用，本机不用管）
  fallback_python.txt      本机过渡期的 Python 路径兜底（不入库；有了 .venv 后可删）
  requirements.txt         Python 依赖清单
  .env.example             环境变量模板。MT5 凭证留空也能用（依赖终端已登录）

【运行数据（重要）】
  strategies\              策略库。训练完成的 best_品种.json 自动出现在这里。
  checkpoints\             训练检查点（续训的依据）。不要删，删了就得从头训。
  training_history_*.json  每个品种的训练分数曲线（网页上的训练分数图就来自它）。
  portfolio_state.json     本地持仓台账（重要！有真实持仓时千万别删）。
  logs\                    日志与 Runner 状态。
  backtest_output\         回测报告输出。

【代码（在 src\ 里，平时不用碰）】
  src\app.py               FastAPI 看板服务（端口 8900）
  src\web\index.html       看板页面
  src\trading\             交易引擎：mt5_client / signal_engine / risk / runner / history
                           sr.py + srlab\ 为支撑/阻力位引擎（开仓止盈止损优化）
  src\model_core\          训练引擎（特征、算子、公式虚拟机）
  src\data_pipeline\       数据加载与 MT5 分块拉取
  src\train_file.py        训练主程序（看板后台调用）
  src\mt5_train.py         "从 MT5 获取并训练"入口（周期可选）
  src\train_island.py      岛模式训练程序（多种群探索 + 精英迁移）
  src\run_backtest.py      回测主程序
  src\tests\               单元测试（77 项）
  scripts\stop_all.ps1     stop.bat 背后的实际停止逻辑，不需要手动碰

【可以放心删的】
  __pycache__\ 文件夹      Python 缓存，删了自动重建
  logs\ 里按时间戳命名的旧日志

【不要删的】
  portfolio_state.json     有真实持仓时删了会导致状态错乱
  checkpoints\             删了无法续训
  trader_config.json       你的绑定和风控设置
  AGENTS.md                给后续 AI 的交接规则

五、先 dry-run，再真实
----------------------
1. 默认 dry-run：信号照算、动作只记日志，不发真实订单。
2. "交易控制"页启动 Runner，在"总览"看信号和持仓，"日志"页看细节。
3. 每 5~10 秒检查价格风控；只有新的已收盘 H1 K 线才重新计算交易信号。
4. 同方向信号不重复开仓；反向信号先平旧仓、确认成功才开反向仓；平仓失败不开新仓。
5. 风控默认：初始止损 -2%；浮盈 1% 止损到成本；2% 锁 1%；3% 锁 2%；4% 锁 3%。
6. 支撑/阻力优化（风控页可开关）：开仓时自动识别附近的支撑带/压力带
   （V3 融合算法：成交量分布 + 极值结构 + ATR 归一化），止损尽量藏在结构位
   外侧、止盈放在对面关键位之前；固定止损 -2% 始终保留，最终取两者中更保守
   （离开仓价更近）的一个。没有合适的关键位时自动退回固定止损。
7. 关键位前"止盈一半"（风控页可开关）：价格到达对面关键位前，先平掉一半仓位
   锁定利润，剩余仓位继续持有（交给阶梯保本和更远的关键位管理）；可以勾选
   "由模型把关"——只有该关键位的模型守住概率 ≥55% 才执行，弱位可能直接突破
   就不止盈一半。全部止盈会顺延到更远的关键位。手数太小无法拆半（如 0.01 手）
   时自动跳过，不影响持仓。
8. 「总览」页有实时 K 线图：K 线 + 支撑/压力带 + 你的开仓价/止损/止盈/止盈一半
   线，滚轮缩放、拖动平移、双击复位，鼠标悬停看单根 K 线明细。
   止损/止盈/止盈一半三条线都可以按住上下拖动，松手后弹出确认框，框里还能
   直接输入精确价格（到价平仓还能指定手数），点"确认执行"才真正生效。
   图上也会画出最近 7 天的历史成交（▲多/▼空入场，圆点离场：绿=盈利红=亏损）。
   品种框可以输入或下拉选择 MT5 终端里的全部品种（没开仓的品种也能看图）。

六、切换真实下单
----------------
0. 在 MT5 终端点亮工具栏的"算法交易 / AutoTrading"按钮。没点亮时 MT5 拒绝一切
   程序订单（日志出现 retcode=10027），看板顶部会显示"MT5 算法交易未开启"。
1. "交易控制"页点击"请求切换为真实下单"。
2. 弹窗里点击"确认执行"。只点第一步不会切换，这是有意的安全设计。
3. 切换后停止并重启 Runner 生效。"立即回到 dry-run"不需要确认，随时可回退。

真实下单前建议确认：策略已回测、手数和止损设置正确、你清楚当前登录的账号。
特别提醒：把 ETH 数据训练的策略绑到 BTCUSD_ 等其他品种属于跨品种使用，效果
没有保证，建议每个品种用各自的数据训练专属策略。

七、故障排查
------------
- 双击 bat 报错：用 start.bat / stop.bat；不要把 PowerShell 长代码写进 bat。
- 任务管理器里看到"两组 python.exe"是正常的：每个程序都是"启动器+真身"两个
  进程（看板一组、Runner 一组）。双击 start.bat 只启动看板这一组；Runner 要在
  "交易控制"页点启动，启动后就会变成两组。stop.bat 会把两组都停干净。
- stop.bat 停止要几秒到十来秒是正常的：它会先给 Runner 发停止信号、等它把
  持仓台账安全写完，再关闭看板（最长等 5 秒），比直接杀进程更安全。
- 页面打不开：再点一次 start.bat；仍失败看 logs\dashboard.log。
- MT5 未连接：手动打开 MT5 终端并登录后刷新网页。
- retcode=10027：MT5 的"算法交易"没点亮。
- retcode=10030：填充模式问题，软件已按品种自动选择，仍出现请反馈日志。
- 模式切换后没生效：确认弹窗点了"确认执行"，且重启了 Runner。
- 训练列表为空：点"只获取并保存"，或确认数据目录里有 .parquet 文件。

八、换 MT5 账户 / 换经纪商会怎样？
----------------------------------
1. 持仓、历史成交、品种列表都是实时从当前登录的 MT5 终端读取的：切换账户后
   不用改软件，Runner 会自动对账——旧账户的仓位消失，新账户的仓位自动纳入
   管理（止盈一半会重新计算计划）。
2. 但品种名字通常每个经纪商不一样（比如 ETHUSD_ 可能变成 ETHUSD 或
   ETHUSD.r）：需要到「策略库」把绑定改成新账户的品种名，否则信号会报
   "K线拉取失败"。策略公式本身与品种无关，重新绑定即可复用。
3. 训练数据按品种名保存：新旧账户品种名相同可以直接复用已有数据文件，
   不同名就到训练页重新"从 MT5 获取"。
4. MT5 的 Python 接口一次只连一个终端：换账户时建议先关掉旧终端、再打开
   新终端并登录，然后刷新网页即可。
5. 如果 .env 里填过 MT5_LOGIN / MT5_PASSWORD / MT5_SERVER，要改成新账号的；
   留空则始终跟随终端当前登录的账号。
